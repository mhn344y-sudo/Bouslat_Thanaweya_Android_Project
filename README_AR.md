# بوصلة الثانوية — مشروع Android أصلي

هذا مشروع Android Studio أصلي باستخدام Kotlin وJetpack Compose، وليس موقعًا أو PWA.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `Bouslat_Thanaweya_Android` من Android Studio.
3. استخدم JDK 17، ثم انتظر Gradle Sync.
4. شغّل التطبيق على هاتف Android أو محاكي.
5. لإنشاء APK: Build > Build Bundle(s) / APK(s) > Build APK(s).
6. ستجد الملف عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## الموجود في النسخة الأولية
- اختيار واحد من أربعة مسارات.
- مواد المسار والمواد المشتركة.
- صفحات المواد والدروس.
- ملخصات ونقاط أساسية وسؤال تدريبي مع تصحيح فوري.
- مؤقت مذاكرة واستراحة 5 أو 10 دقائق.
- إشعار محلي عند انتهاء الاستراحة (بعد منح إذن الإشعارات).
- مساعد تجريبي غير متصل بنموذج ذكاء اصطناعي.
- إعداد الوضع الداكن وتغيير المسار.
- حفظ المسار والوضع الداكن وعدد الدروس المكتملة محليًا.

## تنبيهات مهمة
- هذا مصدر مشروع قابل للبناء في Android Studio، وليس APK مبنيًا ومختبرًا بالفعل.
- يلزم اتصال إنترنت أول مرة لتنزيل Gradle ومكتبات Android.
- المحتوى التعليمي تجريبي وغير مطابق موثقًا لكتب وزارة التربية والتعليم. لا تعتمد عليه للمذاكرة قبل استبداله بمحتوى الكتب الرسمية.
- إشعار الاستراحة يستخدم AlarmManager غير الدقيق، وقد يتأثر بقيود البطارية أو إعدادات الجهاز. لم يتم اختبار سلوكه على أجهزة فعلية.
- مساعد الذكاء الاصطناعي واجهة تجريبية فقط. لا توجد خدمة AI أو مفاتيح API مضمنة.
- لا توجد قاعدة بيانات سحابية أو حسابات مستخدمين في هذه النسخة.
